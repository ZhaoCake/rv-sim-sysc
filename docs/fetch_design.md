# 取指（Fetch）模块设计文档

## 1. 模块概述

取指模块是RISC-V处理器的第一级处理单元，负责从指令存储器中获取当前指令并计算下一条指令的地址。它维护程序计数器（PC）并处理分支和跳转逻辑导致的PC变更。

## 2. 功能描述

取指模块的主要功能包括：

1. 维护和更新程序计数器（PC）
2. 根据当前PC从内存中获取指令
3. 计算下一条指令的地址（PC+4或分支目标地址）
4. 响应分支和跳转指令的控制流变更
5. 支持处理器复位操作

## 3. 接口定义

### 3.1 输入端口

| 端口名称       | 类型            | 描述                    |
|--------------|-----------------|------------------------|
| clk          | sc_in<bool>     | 时钟信号                |
| reset        | sc_in<bool>     | 复位信号                |
| stall        | sc_in<bool>     | 流水线停顿信号           |
| branch_taken | sc_in<bool>     | 分支/跳转是否有效        |
| branch_target| sc_in<Word>     | 分支/跳转目标地址        |
| instruction  | sc_in<Word>     | 从内存获取的指令         |

### 3.2 输出端口

| 端口名称       | 类型             | 描述                    |
|--------------|------------------|------------------------|
| pc           | sc_out<Word>     | 当前程序计数器值         |
| next_pc      | sc_out<Word>     | 下一条指令地址(PC+4)     |
| mem_read     | sc_out<bool>     | 内存读取请求信号         |
| mem_addr     | sc_out<Word>     | 内存读取地址             |
| instr_out    | sc_out<Word>     | 输出到译码模块的指令     |

## 4. 内部结构

### 4.1 内部寄存器

| 名称         | 类型  | 描述                     |
|-------------|------|--------------------------|
| pc_reg      | Word | 内部程序计数器寄存器       |

### 4.2 处理流程

取指模块内部包含一个主要的处理方法 `fetch_process()`，该方法在时钟上升沿触发，具体处理流程如下：

1. **复位操作**：当 `reset` 信号有效时，将PC重置为0，并发出内存读取请求。
2. **正常取指**：在非停顿状态下，取指模块会：
   - 根据分支信号决定下一条指令地址
   - 更新PC值
   - 向内存发出读取请求
   - 将获取的指令转发至译码模块

3. **分支处理**：当 `branch_taken` 信号有效时，PC被设置为 `branch_target`，否则PC增加4。

## 5. 行为模型

```cpp
// 伪代码描述
void fetch_process() {
    if (reset) {
        // 复位处理
        pc_reg = 0;
        pc.write(pc_reg);
        next_pc.write(pc_reg + 4);
        mem_read.write(true);
        mem_addr.write(pc_reg);
        instr_out.write(0);  // 复位期间输出NOP
    } 
    else if (clk上升沿) {
        if (!stall) {
            // 检查是否需要分支跳转
            if (branch_taken) {
                pc_reg = branch_target;
            } else {
                pc_reg = pc_reg + 4;  // 正常PC增加
            }
            
            // 更新输出
            pc.write(pc_reg);
            next_pc.write(pc_reg + 4);
            
            // 内存读取请求
            mem_read.write(true);
            mem_addr.write(pc_reg);
            
            // 输出指令
            instr_out.write(instruction);
        }
    }
}
```

## 6. 性能特性

### 6.1 时序特性

- **时钟依赖**：模块在时钟上升沿更新状态
- **延迟**：从PC确定到指令获取需要1个时钟周期
- **吞吐量**：在无停顿情况下，每周期可以获取一条新指令

### 6.2 资源需求

- 存储资源：一个32位程序计数器寄存器
- 组合逻辑：用于下一PC值的计算

## 7. 与其他模块的接口

### 7.1 与Memory模块的接口

取指模块通过以下信号与Memory模块通信：
- `mem_read`: 指示Memory模块读取指令
- `mem_addr`: 提供要读取的地址
- `instruction`: 接收Memory模块返回的指令数据

### 7.2 与Execute模块的接口

Execute模块通过以下信号控制取指模块的行为：
- `branch_taken`: 指示是否需要跳转
- `branch_target`: 提供跳转目标地址

### 7.3 与Decode模块的接口

取指模块向Decode模块提供以下信息：
- `pc`: 当前指令的地址
- `instr_out`: 当前获取的指令

## 8. 扩展性考虑

### 8.1 潜在扩展

- **指令预取**：可以添加指令预取缓冲区提高性能
- **分支预测**：可以集成简单的分支预测逻辑
- **多级Pipeline支持**：可以扩展支持更复杂的流水线控制

### 8.2 RTL实现考虑

在转换为RTL时，需要特别注意以下方面：
- PC值的时序正确性
- 复位操作的同步逻辑
- 分支跳转逻辑的延迟

## 9. 验证策略

对取指模块的验证主要包括：
- 验证PC按照预期更新
- 验证分支处理逻辑正确
- 验证与内存接口交互正确
- 验证复位行为正确
